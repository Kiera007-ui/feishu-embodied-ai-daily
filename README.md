# 具身智能每日推 → 飞书

## 当前架构

**ChatGPT 生成每日内容 → Vercel 纯转发页 → 飞书群自定义机器人**

这个项目不调用 OpenAI API，也不使用 Vercel Cron。Vercel 只负责把已经生成好的文本转发到飞书。

### 环境变量

只需要：

`FEISHU_WEBHOOK_URL`

值为目标飞书群自定义机器人的 Webhook 地址。

### 防重复发送

当前版本做了三层保护：

- 打开网页或访问 GET 接口不会发送消息；
- 只有显式 POST 请求才会发送；
- 页面在一次会话内会记录已发送内容并阻止重复点击；服务端也会在短时间内抑制相同文本的重复请求。

### 页面使用

打开项目首页，把完整日推文本粘贴到文本框。首行必须以：

`具身智能每日推｜YYYY.MM.DD`

开头，然后点击“发送到飞书”。

### 消息口径

内容生成规则不放在 Vercel 项目内，由 ChatGPT 每日任务维护。当前要求：

- 只保留当天真正有讨论度或刚出现且影响行业认知的重要消息；
- 优先使用机器之心 / 机器之心Pro、新智元、量子位、AI前线/InfoQ、极客公园、36氪/硬氪、投资界、甲子光年、晚点、硅星人、你好太空，以及创始人/核心高管原始演讲、采访、官方技术博客和高质量视频；
- 同一事件已有上述专业来源时，不使用弱转载站或普通聚合媒体替代；
- 国际资本市场或海外公司事件可使用 Reuters 等一线国际新闻机构或公司原始来源；
- 输出保持“消息概述 + 来源 + 链接”；
- 不添加【跨界】【核心】【重点】【高热】【突发】等判断性标签；
- 不写趋势总结、价值判断、最终建议或策略性收尾；
- 默认 4–6 条，宁少勿滥。
